# Reserved commercial E7Q-IR component

This is the publication/distribution boundary for future rights-cleared E7Q-IR
implementation. No implementation is present yet. The existing `e7q` package,
including its IR modules, remains Apache-2.0.

Designated new software will use the unmodified [PolyForm Noncommercial
1.0.0 licence](LICENSE), or a separately executed commercial agreement for uses
outside its permitted scope. This is source-available software, not OSI open source.
This README is CC-BY-SA; it does not add or narrow licence permissions.

Before publishing code, follow the [commercial policy](../../docs/licensing/COMMERCIAL_POLICY.md)
and add each file's SHA-256 and rights-clearance reference to the component
register. Each code file must carry:

```text
SPDX-License-Identifier: PolyForm-Noncommercial-1.0.0
Required Notice: Copyright 2026 Oleksandr Razinkov
```

Keep copied third-party/published material and its notices distinguishable.
Do not move existing Apache files here and represent them as exclusively
licensed. The standard Apache wheel and source archive exclude this directory.
Commercial components require a separate package/build with truthful metadata,
their licence and all dependency notices; no build or paid product exists here yet.

# Milestone 22 — Comparative-experiment evidence

E7Q v1.0.0rc11 adds a fail-closed one- or two-factor experiment manifest,
descriptive cell aggregation, metric-preserving effects, two-factor
interaction contrasts, explicit resource and replication postures, and a
six-level claim boundary.

The command is:

```bash
e7q assess-experiment experiment.json -o comparative-report.json
```

Automatic conclusions stop at `OBSERVED_DIFFERENCE`. Repeatability, domain
quality, practical advantage, and computational quantum advantage require
stronger evidence and methods.

See [COMPARATIVE_EXPERIMENTS.md](COMPARATIVE_EXPERIMENTS.md).
